# Archival Packager

デジタル資料から、OAIS 参照モデルの情報パッケージ（SIP / AIP）を作成する
デスクトップアプリケーションです。macOS と Windows に対応します。

フォーマット識別（Siegfried / PRONOM）、ウイルス検査（ClamAV）、チェックサム
（SHA-256）、技術メタデータ（DFXML）、保存処理記録（METS / PREMIS）の生成を、
コマンドライン操作なしで行えます。
